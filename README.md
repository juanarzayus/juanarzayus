## Sobre mí

Soy desarrollador y estudiante de Ingeniería en **Cali, Colombia**. Me interesa crear aplicaciones web completas: desde la experiencia visual y el frontend hasta las bases de datos, la autenticación y los pagos.

Actualmente estoy desarrollando soluciones con **Next.js**, **React** y **TypeScript**, además de explorar el diseño 3D para la web con **Three.js** y **React Three Fiber**. Me gusta convertir necesidades reales en productos digitales útiles, mantenibles y fáciles de administrar.
